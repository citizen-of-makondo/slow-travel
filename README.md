# Slow Travel — сайт

Одностраничный сайт для авторских туров по Балканам (Алексей и Лариса, Сербия).

Статика: HTML + CSS + ~1 КБ JS. Без сборки, без зависимостей, без бэкенда.

## Запуск

```bash
python3 -m http.server 5173
```

Открыть http://localhost:5173

## Структура

```
index.html                    вся разметка и контент
styles/tokens.css             дизайн-токены (цвет, типографика, ритм, motion)
styles/base.css               reset, базовая типографика, зерно бумаги, a11y
styles/layout.css             сетка, секции, кнопки, scroll-reveal
styles/components/*.css       nav, hero, about, tours, journal, footer
scripts/main.js               reveal при скролле, «липкая» шапка, год в футере
styles/components/crawler.css улитка, ползущая по нижней кромке шапки
assets/logo/                  логотип-улитка (аватар канала @slowtour)
assets/photos/                фотографии (пока пусто)
```

### Логотип

Взят из аватара Telegram-канала @slowtour (320×320, белая улитка на терракотовом круге).
Используется в шапке, в футере и как favicon / apple-touch-icon.

| Файл | Где |
|------|-----|
| `logo-96.png` | шапка и футер (отрисовка 28–36 px, запас под 2–3x) |
| `logo-192.png` | favicon высокого разрешения |
| `favicon-32.png` | favicon |
| `apple-touch-icon.png` | иконка на домашнем экране iOS |
| `logo-320.jpg` | оригинал, он же `og:image` |

Оригинал — растр 320 px. Если у ребят есть векторный исходник, лучше заменить на SVG:
логотип штриховой, в вектор ляжет идеально и станет ~1 КБ вместо 15.

## Как обновлять контент

**Туры** — блок `<ul class="tours">` в `index.html`. Название тура ведёт на его анонс
в канале (`https://t.me/slowtour/<id>`), кнопка «Забронировать место» — на канал целиком:

| Тур | Пост |
|-----|------|
| Черногория | t.me/slowtour/2390 |
| Босния и Герцеговина | t.me/slowtour/2444 |
| Джердап | t.me/slowtour/2196 |
| Марокко | t.me/slowtour/2312 |

Статус мест задаётся атрибутом:

| `data-status` | Как выглядит |
|---------------|--------------|
| `open`        | зелёная точка, «Есть места» |
| `few`         | терракотовая, «Осталось N мест» |
| `none`        | серая пунктирная, «Мест нет» |

**Журнал** — блок `<div class="journal">`. Три карточки, тексты из Threads. Ссылка
«Читать в Threads» ведёт на конкретный пост
(`https://www.threads.com/@_slow_travel/post/<code>`), а не на профиль. Код поста
берётся из адресной строки, когда открываешь пост в Threads.

**Фото туров** — `assets/photos/tour-*.jpg`, 480×320 (3:2), взяты из постов канала:

| Файл | Что на фото | Пост |
|------|-------------|------|
| `tour-montenegro.jpg` | пики Проклетие | t.me/slowtour/2390 |
| `tour-bosnia.jpg` | Себиль на Башчаршии, Сараево | t.me/slowtour/2298 |
| `tour-djerdap.jpg` | крепость Голубац над Дунаем | t.me/slowtour/2196 |
| `tour-morocco.jpg` | мечеть Хассана II, Касабланка | t.me/slowtour/2312 |

Замена: положить файл с тем же именем, пропорции 3:2, ширина от 480 px. Разметку
трогать не нужно — только `alt` в `index.html`, если сменился сюжет.

**Фото пары** — `assets/photos/aleksey-larisa.jpg`, 600×750 (4:5), Которский залив,
из поста t.me/slowtour/2460. Замена: файл с тем же именем, пропорции 4:5.

Telegram отдаёт превью максимум ~800 px по длинной стороне, так что на ретине
кадр слегка мягкий. Если у ребят есть оригинал — заменить на 1200×1500.

Плейсхолдер `.about__placeholder` остался в разметке как запасной вариант: CSS
прячет его через `:has(img)`, и он снова появится, если убрать `<img>`.

**Цвета и шрифты** — только `styles/tokens.css`. Ничего не захардкожено по файлам.
Терракотовых токена два: `--color-clay` для декора (солнце, рамки, стрелки) и
`--color-clay-text` — затемнённый, для мелкого текста, чтобы держать 4.5:1.

**Зоны нажатия** — все интерактивные элементы имеют `min-height: 44px`. Если добавляете
новую ссылку в футер или меню, дайте ей ту же высоту, иначе на телефоне в неё не попасть.

**Улитка** — SVG прямо в разметке `<header>`, ползёт по нижней кромке шапки.
Шапка липкая, поэтому улитка видна на любой прокрутке. Две ручки в
`styles/components/crawler.css`:

- `--crawl-duration` — проход экрана, сейчас `120s` (на десктопе ~12 px в секунду).
  Больше значение — медленнее ползёт.
- `--crawl-head-start` — отрицательная задержка, сейчас `-7s`. Улитка стартует уже
  выползшей из-за левого края, а не ждёт своей очереди за кадром.

След растёт тем же таймингом, поэтому всегда заканчивается ровно под улиткой.
При `prefers-reduced-motion` улитка просто сидит на линейке.

## Аналитика (Umami)

Umami не ставит куки и не собирает персональные данные — баннер согласия не нужен.

Включение в два шага:

1. Завести сайт в панели Umami — [cloud.umami.is](https://cloud.umami.is) даёт бесплатный
   тариф (100 000 событий в месяц, до 3 сайтов). Альтернатива — self-hosted Umami,
   тогда поменяйте и `scriptSrc`.
2. Скопировать оттуда **Website ID** и вставить в `ANALYTICS.websiteId`
   в [`scripts/main.js`](scripts/main.js). Одна строка, больше ничего.

Пока в поле заглушка, скрипт не подключается вообще: ни запросов, ни ошибок в консоли.
`ANALYTICS.domains` ограничивает сбор боевым доменом, поэтому локальная разработка
статистику не портит.

### Что считается кроме просмотров

На ключевые ссылки повешен `data-umami-event` — Umami сам считает клики, без кода:

| Событие | Где |
|---------|-----|
| `tg-header`, `tg-booking` | кнопки «Канал в Telegram» и «Забронировать место» |
| `hero-tours` | «Смотреть маршруты» в первом экране |
| `tour-montenegro`, `tour-bosnia`, `tour-djerdap`, `tour-morocco` | строки туров |
| `journal-kopaonik`, `journal-spomeniki`, `journal-novi-pazar` | карточки журнала |
| `contact-channel`, `contact-larisa`, `contact-instagram`, `contact-threads` | блок контактов |

Самое полезное здесь — сравнить `tour-*` между собой (какое направление цепляет)
и `contact-larisa` против `contact-channel` (пишут напрямую или идут читать канал).
Добавляете ссылку — добавьте атрибут, иначе клик не попадёт в статистику.
